Abstract

Long-horizon humanoid tasks require selecting behaviors that advance a language-specified goal while maintaining physically feasible transitions between them. Connecting visual task understanding to continuous whole-body execution remains challenging because a semantically appropriate skill may be incompatible with the robot's current posture or contact configuration.

We propose Jev-WBC, a hierarchical framework that formulates humanoid vision-language-action execution as closed-loop arbitration over composable atomic skills. Each skill is represented by an initiation condition, a parameterized control policy, and a termination criterion. A visual perception frontend converts recent observations into structured scene descriptions, which are combined with language instructions, proprioceptive summaries, and execution history for Jev-based task relevance and progress assessment. To account for the physical requirements of skill composition, a transition feasibility model learned from successful and failed skill transitions constrains candidate selection using the robot's motion and contact state. An event-triggered execution mechanism then determines when to continue, terminate, or replace the active skill, and invokes recovery behaviors when progress stalls or execution deviates from the intended outcome.

Selected skills provide motion targets to a low-level whole-body controller, separating semantic decision-making from continuous motion execution. Jev-WBC establishes a framework for investigating how structured decision models, transition feasibility, and execution feedback can jointly support long-horizon humanoid behavior.

Composable Atomic Skills

Jev-WBC formulates humanoid execution as closed-loop arbitration over a library of composable atomic skills. Each skill is represented by an initiation condition, a parameterized control policy, and a termination criterion, so the high-level decision layer reasons about which behavior to invoke while the low-level controller handles how it is executed.
